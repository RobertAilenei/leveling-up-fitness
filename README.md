# ⚔️ Leveling Up Fitness

A modern, Dark-Mode Workout & Calorie Tracker inspired by the anime **Solo Leveling**. Built with React, CSS Modules, and modern DevOps practices using GitHub Actions.

## 🎮 Features

- **Dashboard**: View your workout statistics at a glance
- **Workout Tracking**: Log your workouts with type, duration, and calories burned
- **Calorie Counter**: Track total calories burned
- **Dark Theme**: Solo Leveling inspired dark blue aesthetic
- **Responsive Design**: Works seamlessly on desktop and mobile
- **Component-Based**: Modular, maintainable React components

## 🛠️ Tech Stack

- **Frontend**: React 18+
- **Styling**: CSS Modules
- **Build Tool**: npm
- **CI/CD**: GitHub Actions
- **Development**: ESLint for code quality

## 📋 DevOps Pipeline Overview

This project demonstrates modern DevOps practices:

### GitHub Actions Workflows

1. **Linting** - Code quality checks
2. **Building** - Create optimized production build
3. **Testing** - Run unit tests
4. **Artifacts** - Store build outputs for deployment

### Workflow Triggers

- **On Push**: Triggered when code is pushed to `main` or `develop` branches
- **On PR**: Automated checks run before merging pull requests
